Versionshistorie

Hier finden Sie eine Übersicht über die Änderungen und Erweiterungen in den Versionen von SmartBillParser. Nicht explizit aufgeführte Zwischenversionen beinhalten kundenspezifische Optimierungen und Detailanpassungen.

v3.1.1 — 21.10.2026

  • Export als ZUGFeRD EXTENDED Profil
  • Erweiterung der Attribute in der Oberfläche und den Verkäufer-Eigenschaften
  • Erweiterung der Attribute des unterstützten XML Schemas

v3.0.6 — 23.08.2026

  • Automatisierte Validierung von ZUGFeRD-Dateien zur Prüfung von Eingangsrechnungen

v3.0.5 — 23.08.2026

  • Manuelle Validierung von ZUGFeRD-Dateien zur Prüfung von Eingangsrechnungen

v3.0.2 — 22.08.2026

  • Unterstützung für ZUGFeRD Version 2.5.2
  • Windows-App ist vertrauenswürdig signiert

v3.0.0 — 11.08.2026

  • Unterstützung für ZUGFeRD Version 2.5
  • Mehrmandantenfähigkeit in Pro-Lizenz
  • Sende Datei manuell/automatisch als Email per MAPI in Windows-App
  • Verschiebe Datei optional bei Erfolg in Archive-Ordner
  • Zeige Notifications optional

v2.5.8 — 18.05.2026

  • Verbesserung der PDF/A-Konformität
  • Änderung PDF/A‑OutputIntent‑Farbprofil auf ein weit verbreitetes Profil
  • Möglichkeit eigenes Farbprofil in den Settings zu hinterlegen
  • Anzeige der PDF/A-Errors als Warnings. Siehe Erklärung dazu in den FAQs.

v2.5.6 — 08.04.2026

  • Unterstützung für ZUGFeRD Version 2.4
  • Auswahl ZUGFeRD Profil in Settings (EN16931 und XRECHNUNG)

v2.5.4 — 05.02.2026

  • Anpassung der Lizenz Features und kostenlose Basis-Lizenz
  • Export ohne PDF möglich
  • Abweichende Lieferanschrift
  • Bugfixes

v2.5.3 — 27.01.2026

  • Erstellung eines Validierungsberichts
  • Optimierte PDF-Erstellung für internationale Rechnungsformate
  • Käufer USt-ID
  • Bugfixes

v2.5.2 — 07.12.2025

  • MacOS Installer

v2.5.1 — 07.12.2025

  • Debian/(K)Ubuntu Installer

v2.5.0 — 05.12.2025

  • Verbesserte Performance bei der Batch-Konvertierung
  • Aktualisierung der XRechnung-Validierungsregeln auf Stand 2026
  • Bugfixes

v2.4 — 15.11.2025

  • Unterstützung für ZUGFeRD Version 2.2
  • Neue Benutzeroberfläche für die Konfigurationsverwaltung

v2.3 — 05.09.2025

  • Einführung der Pro-Lizenz Features
  • Direkter Import aus ERP-Schnittstellen
  • Stabilitätsverbesserungen
